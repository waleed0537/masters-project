I selected a **virtual machine (VM) running Ubuntu 22.04 LTS** instead of a dual-boot configuration because it provides a more flexible and efficient development environment by allowing Windows and Linux to run simultaneously. This is important for my project workflow, as I need to frequently switch between Windows-based machine learning development (such as model training, Python environments, and analysis tools) and Linux-based components (such as Asterisk, VoIP services, and security-related tools). A bridged-network VM provides reliable network connectivity, allowing Ubuntu to behave like an independent machine on the local network, which is beneficial for SIP communication and Asterisk testing. I chose **Ubuntu 22.04 LTS** because it is a stable, long-term supported release with strong compatibility with enterprise tools, VoIP frameworks, security libraries, and research environments. Using an LTS version reduces the risk of dependency conflicts and ensures a consistent platform throughout the development and evaluation phases of the project.
